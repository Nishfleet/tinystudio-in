# Launch video source

HyperFrames (Apache-2.0, https://github.com/heygen-com/hyperframes) composition for the 80 s TinyStudio launch video. Script and claim sources: `SCRIPT.md`.

- `index.html` is the whole composition. `assets/` holds the two live-site screenshots, one screenshot of the repo's `public/index.html` Website Correction section, and the trimmed music clip.
- Check: `npm run check`. Preview: `npm run dev`. Render: `npm run render -- -o out.mp4` (1920x1080, one render at a time).
- The rendered mp4 is not in git. It is an asset on the draft release `launch-video`.
- Not posted anywhere public.
