# 90-Day Plan Start Here

Start state: TinyStudio is at pre-customer / pre-revenue operating-model parity with the solo AI agency article and the agent-agency diagram. `npm run agent:parity` proves the diagram-shaped architecture exists. The next bottleneck is not more product surface. It is the first external proof batch.

## Day 1 Mission

Record the first five approved Loom audits.

Current batch:

- ByteMe Networks
- IT Umbrella Group
- Talos Cyber Solutions
- Xentz Technologies
- YPM IT Solutions

## Run Order

1. Open the recording mission:

   ```bash
   npm run growth:start -- --view=record
   ```

2. Check the scripts:

   ```bash
   npm run prospect:rehearsal -- --limit=5
   ```

3. Record the five Looms from the teleprompter.

4. Paste the Loom URLs into:

   ```bash
   npm run market:after-recording -- --from-clipboard
   ```

5. Refresh the proof cockpit:

   ```bash
   npm run market:proof-cockpit
   ```

6. Send through contact forms or DMs while sender trust is dirty.

7. After sends or follow-ups, run:

   ```bash
   npm run market:learn
   ```

## Do Not Build Yet

Use `docs/strategy/friction-triggered-build-backlog.md` for later builds. Do not build cold email, intake forms, background agents, a hard-wired model router, or public case-study pages until real sales or delivery friction proves they are needed.

Do not confuse `agent:parity` with live autonomous delivery. It is the pre-revenue operating packet and verification gate, not proof of a paid-client agent swarm.

## Success For The First Week

- 5 Looms recorded.
- 5 sends completed through contact forms or DMs.
- Follow-up dates set.
- Market learning written before changing niche, hook, offer, or channel.
- No revenue, margin, ranking, sales-lift, or paid-client proof claims.
