# Five to Nine Leader-Led Build Brief

Status: reference packet rebuilt after the first 0509 concept proof was rejected.

## Decision

Build the next 0509 concept from the top-performing proxy leader set, not from generic Mobbin relevance.

The design direction should feel like a serious SaaS intelligence product for growth teams:

- Peec AI and Profound for AI/search visibility structure.
- Sprout Social for competitor-performance reports and enterprise SaaS discipline.
- Similarweb, Semrush, Ahrefs, AlphaSense, and Meltwater for source-backed performance proof and category gravity.
- Clearbit, Mixpanel, and Fey only as visual proxies where Mobbin lacks exact leader screens.

## What Changed

The first concept packet is superseded because it did not first prove the top 6-8 niche leaders. It had useful visual work, but the order was wrong.

This pass starts with the leader ledger:

1. define the exact niche
2. score leaders with public performance proxies
3. pull Mobbin Pro references
4. separate exact references from visual proxies
5. remix only compatible ingredients

## New Visual Direction

Working name: **Visibility Command Brief**.

The first fold should show:

- disciplined SaaS nav
- one large headline about seeing market moves before they cost you
- short support copy that says source-backed, pilot-ready, and growth-team focused
- primary CTA: `Request pilot access`
- secondary CTA: `See sample brief`
- a real 0509-style product artifact with:
  - source/platform filters
  - competitor rows
  - detected change
  - confidence/source status
  - recommended next action

## Ingredient Lock

Use:

- Peec-style huge headline and calm white product artifact.
- Profound-style metric tabs and source/platform filters.
- Sprout-style competitor report table and mature enterprise nav.
- Similarweb/Ahrefs/Semrush evidence only for category framing, not copied claims.
- One sharp signal accent for `Live`, `Changed`, and `Needs review`.

Reject:

- generic AI gradient hero
- Mobbin Proving Lab house-style cards
- unsupported customer logos
- invented ROI numbers
- fake enterprise trust badges
- visual proxies mislabeled as top-performing references
- dashboard wallpaper with no readable product job

## Concept Set To Generate

Create three screenshot-level directions:

1. **Visibility Command Brief**: minimalist, product-artifact led, safest default.
2. **Market Signal Ledger**: typographic/editorial, date-stamped evidence and brief rhythm.
3. **After-Hours Intelligence Room**: dark/premium, only if source text and charts stay readable.

Each concept must use different structure, typography rhythm, artifact treatment, CTA placement, and section order. Color swaps do not count.
