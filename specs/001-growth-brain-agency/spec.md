# Feature Specification: Growth Brain Agency Operating Kit

## User Outcome

Nish can sell and deliver the first 7-Day Site Revenue Leak Sprint without waiting for SaaS, a redesigned website, or a large team.

## Non-Goals

- Build a SaaS product.
- Automate client ad accounts, email platforms, analytics, or payments.
- Promise specific revenue, ranking, ROAS, or conversion lift.
- Replace human approval with autonomous publishing.

## Requirements

- Define one clear first offer.
- Define the best first client profile.
- Provide a 7-day delivery workflow.
- Provide the first seven repeatable agent workflows.
- Provide a reusable client brain template.
- Provide first-client outreach assets.
- Provide sales assets for buyer rooms, proposals, calls, objections, and follow-ups.
- Provide a niche-specific one-page sales sheet for the first managed IT/cybersecurity wedge.
- Provide quality gates for proof, acceptance, scoring, and client delight.
- Provide retention assets for health scoring, expansion, and case studies.
- Provide vertical playbooks for faster niche-specific audits.
- Provide AI/search visibility prompts and workflow without unsupported visibility promises.
- Provide implementation handoff and client communication templates.
- Provide value and pricing rules.
- Provide scaffold commands for prospects and clients.
- Provide command-center and metrics assets for daily execution.
- Provide a live daily command that summarizes prospect/client next actions.
- Provide a browser growth cockpit that links the active daily workflow surfaces.
- Provide a live metrics command that exports the current funnel scoreboard.
- Provide a proof and learning library export so real patterns compound over time.
- Provide prospecting query bank, first-50 template, warm-network scripts, and batch import.
- Provide prospect contact-plan generation from a prospect website or fixture.
- Provide Loom package generation from prospect folders.
- Provide Loom recording script generation from prospect folders.
- Provide batch recording queue export for the closest-to-send prospects.
- Provide a browser recording cockpit with scripts, links, Loom URL fields, channel-specific send copy, and copyable commands.
- Provide a focused recording teleprompter for the closest-to-send prospects.
- Provide Loom link injection so recorded Looms update buyer room, outreach, and package files.
- Provide next-message generation for email, contact-form, DM, follow-up, reply, and booked-call sends.
- Provide a prospect outbox for recorded Looms that are ready to send.
- Provide send-prep generation so one pasted Loom URL updates send surfaces, creates the next message, checks readiness, and writes a send package.
- Provide batch send-prep so multiple recorded Loom URLs can create send packages in one run.
- Provide batch sent completion so one command marks a sent batch and schedules follow-ups.
- Provide prospect stage tracking for sent Looms, follow-ups, replies, calls, wins, and losses.
- Provide a due follow-up cockpit with channel-specific copy and stage commands.
- Provide reply-prep generation so replies become call-booking packages.
- Provide sales call prep generation from prospect folders.
- Provide call-booked prep so a booked call creates confirmation copy, call agenda, close guardrails, and next-step commands.
- Provide post-call close prep so a sales call creates a scoped decision follow-up, payment CTA, and conversion commands.
- Provide prospect-to-client conversion after a won sprint.
- Provide client kickoff message generation.
- Provide client delivery cockpit generation for paid sprint execution.
- Provide readiness checks for prospect Looms and client sprint handoffs.
- Provide outbound claim-safety checks for generated prospect, sales, and client-facing materials.
- Provide a 14-day action plan to close the first paid sprint.
- Preserve Mobbin as the reference workflow for design direction.
- Include a site architecture workflow for B2B/local-service clients where search intent and AI visibility matter.
- Include an agency operating model for expanding from a first wedge into a sticky weekly growth desk.

## Acceptance Checks

- `npm test` passes.
- The Growth Brain kit has all required files.
- Every agent has inputs, checklist, output, approval gate, and measurement sections.
- The offer avoids unprovable claims.
- The sprint checklist covers Day 1 through Day 7.
- Prospect and client scaffold commands create the expected private folders.
- Prospect import command creates expected private folders from a text list.
- Prospect contact-plan command creates a send-route file without guessing emails.
- Prospect package command creates an audit-ready Loom package.
- Prospect recording script command creates a record-ready talk track.
- Prospect queue command exports the next recording batch.
- Prospect cockpit command exports the next recording batch as a browser page.
- Prospect teleprompter command exports a focused recording page.
- Prospect Loom link command updates the send surfaces after recording.
- Prospect message command writes the next send/follow-up message with channel-specific versions.
- Prospect outbox command exports recorded Looms with channel copy and stage commands.
- Prospect send-prep command writes the final send package after a Loom is recorded.
- Prospect batch send-prep command writes send packages from a Loom-link file.
- Prospect batch-sent command marks a sent Loom-link batch as sent and schedules follow-ups.
- Managed IT one-page sales sheet exports to printable HTML.
- Prospect stage command schedules follow-ups and records pipeline movement.
- Prospect follow-up cockpit exports due follow-ups as a browser page.
- Prospect reply-prep command writes a reply package and call prep.
- Prospect call-prep command creates a focused sales-call packet.
- Prospect call-booked-prep command writes a booked-call package and moves the prospect to call-booked.
- Prospect close-prep command writes the post-call close package.
- Prospect convert command creates a client sprint folder and preserves the audit context.
- Client kickoff command creates the first client message and context checklist.
- Client cockpit command creates a paid-sprint delivery board.
- Prospect readiness command identifies draft versus send-ready Loom packages.
- Client readiness command identifies draft versus handoff-ready sprint folders.
- Outbound claim-safety command blocks unprovable claims in generated materials.
- Daily command-center command reports the next actions from current prospect and client state.
- Growth cockpit command exports a browser start screen for daily work.
- Live metrics command exports current funnel counts and conversion rates.
- Proof library command exports current audit patterns, notes, client learnings, and reusable claim guardrails.
- Sales, quality, and retention artifacts are covered by `npm test`.

## Data Touched

- No client data is committed.
- Client brain templates are blank reusable documents.
- Future client copies must stay private unless sanitized and approved.

## Launch Risk

The main risk is selling vague AI services. The control is a productized sprint with concrete deliverables and no unprovable results promise.
