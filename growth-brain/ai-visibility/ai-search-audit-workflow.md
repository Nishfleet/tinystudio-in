# AI/Search Visibility Audit Workflow

## Goal

Find language, proof, and page-structure gaps that affect how buyers understand the business across search and AI-assisted research.

## Inputs

- Client website
- Competitor URLs
- Main buyer type
- Main service/product category
- Location or niche
- Prompt bank

## Steps

1. Run 5-10 category and buyer-intent prompts.
2. Capture repeated phrases and questions.
3. Note which competitors or sources appear.
4. Compare the client's pages against those buyer questions.
5. Add true, useful phrases to the site architecture plan.
6. Turn repeated questions into FAQ or page-section recommendations.

## No-Hack Rules

- Good AI/search visibility starts with good SEO: crawlable pages, clear page jobs, helpful answer sections, true proof, and strong internal links.
- Do not recommend LLMs.txt files, AI.txt files, special markdown, AI-only pages, fake mentions, hidden text, keyword stuffing, arbitrary chunking, or rewriting content only for AI systems.
- Do not recommend buying backlinks, link schemes, fake citations, fake reviews, spam directory blasts, or doorway pages.
- Use structured data when it already fits the content and normal SEO strategy; do not present it as required for generative AI visibility.
- If a page cannot answer a buyer question clearly for a human, fix that before worrying about AI systems.

## Search Trust Layer

Run search trust after the conversion fix. Check page title/meta, headings, internal links, service-page structure, buyer-question FAQs, schema where useful, sitemap/canonical/crawl basics, and local/service-area relevance. Use off-site only for real trust and distribution: citations, Google Business Profile improvements, partner/vendor listings, reviews/testimonials, proof assets, citeable useful pages, and real PR/community mentions.

## Output

- AI/search phrase map
- competitor/source mentions
- missing buyer questions
- FAQ recommendations
- page-section recommendations
- search trust fixes
- claim risks

## Approval Gate

Client must approve every phrase that implies capability, location, certification, pricing, guarantee, or compliance expertise.

## Measurement

Track Search Console queries, qualified inquiries, on-page engagement, sales-call questions, and any approved AI/search visibility checks over time.
