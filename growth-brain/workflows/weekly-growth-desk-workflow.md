# Weekly Growth Desk Workflow

## Goal

Retain the client by running the weekly marketing learning loop.

## Weekly Promise

Each week TinyStudio delivers:

- one performance review
- one prioritized improvement
- one updated competitor/search/AI visibility note
- one client brain update
- one next-week recommendation

## Weekly Cadence

| Day | Action |
|---|---|
| Monday | Pull metrics and review previous action |
| Tuesday | Pick the highest-leverage next improvement and, when useful, run `growth-brain/agents/marketing-agent-workbench.md` for research inputs |
| Wednesday | Draft or implement the improvement |
| Thursday | Human/client approval |
| Friday | Send weekly report and update client brain |

## Retainer Scope

Pick one primary lane per month:

- Site architecture and AI/search visibility
- Product or landing page conversion
- Email/SMS campaigns
- Ad angle and creative concepts
- Competitor watch
- Analytics and decision support

## Retention Rule

The client should feel that TinyStudio is keeping the growth system moving without them managing five vendors.

## Expansion Rule

Add an adjacent lane only when:

- the current lane is stable
- the client has the data or assets needed
- the new lane has a clear owner and output
- the weekly report can measure it
