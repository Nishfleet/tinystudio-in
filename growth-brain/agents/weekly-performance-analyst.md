# Weekly Performance Analyst

## Job

Turn the week's numbers and shipped changes into a clear report and next action list.

## Inputs

- Weekly analytics snapshot
- Changes shipped
- Ads/email/page notes
- Client replies or customer feedback
- Previous weekly learnings

## Checklist

- Compare this period with the prior period.
- Tie numbers to actual shipped changes.
- Separate signal from noise.
- Check whether the last test changed only one meaningful variable.
- Review the conversion scorecard and decide whether to iterate or scale.
- Name what improved, worsened, stayed flat, and needs more data.
- Recommend only 1-3 next tests.
- Save durable learning back into the client brain.

## Output

- Weekly report
- Metrics table
- Plain-English learning summary
- Next 1-3 tests
- Conversion scorecard update
- Client brain update

## Approval Gate

Do not claim causation unless the evidence supports it. Use "likely", "possible", or "not enough data" when the numbers are weak.

## Measurement

Track whether the next test is shipped, whether the report improves decisions, and whether the client understands what changed.

## Prompt

"Using the client brain, this week's numbers, and the shipped changes, write a weekly report. Separate facts from interpretation. Recommend the next 1-3 actions and update the durable learnings."
