# Marketing Agent Workbench

## Job

Run repeatable marketing-agent loops that create useful research, assets, and alerts without turning the workflow into a fragile tool stack.

Use Codex, browser automation, scraping, model routing, or other agent tools as available. Hermes, Nous Portal, and similar tools are optional infrastructure, not the workflow itself.

## Inputs

- Client brain
- Current offer and positioning
- Approved proof and claim ledger
- Competitor URLs
- Source list or prompt bank
- Current campaign, page, ad, or email context
- Clear output destination

## Checklist

- Start with one business question, not a broad browsing task.
- Define the exact output before the agent runs.
- Use the smallest repeatable loop that can run weekly or daily.
- Keep the kill list sharp: stop tasks that do not create replies, better pages, better ads, better emails, or client learnings.
- Store useful findings in the client brain or proof library.
- Flag every claim that needs client approval.
- Keep manual approval before publishing, spending, messaging, or changing client systems.

## Core Loops

| Use Case | Workflow Translation | Output |
|---|---|---|
| Daily market research | Search current category news, buyer questions, competitor posts, and regulatory changes. | Brief with 5 useful signals, why they matter, and one action. |
| Content creation | Research one topic, choose an angle, draft channel-native assets, and mark proof gaps. | Post, email, or page-section draft with source notes. |
| Competitor website monitoring | Check competitor pricing, pages, offers, case studies, and launches. | Change log with useful moves and moves to avoid. |
| Lead research | Extract company facts, page leaks, proof gaps, contact routes, and wedge fit. | Prospect folder notes and Loom prep context. |
| Podcast or voice briefing | Turn the best weekly findings into a short briefing script. | 3-5 minute voice/readout brief for Nish or the client. |
| Paid ads ops | Pull recent performance, find winning audiences and weak creatives, generate approved test ideas. | Morning brief with what to test, pause, or watch. |

## Output

- Source list
- Short summary
- Exact marketing action
- Proof or approval gaps
- Destination file updated
- Next trigger

## Approval Gate

No agent may publish, send, spend, pause ads, change site copy, or update client systems without explicit human approval and rollback notes.

## Measurement

Track replies, qualified calls, page conversion events, ad performance, email clicks, objections learned, and whether the loop produced an action that shipped.

## Prompt

"Using the client brain and the conversion optimization playbook, run the smallest useful marketing-agent loop for this goal. Return the sources used, the useful signals, the exact action, the proof gaps, and the next trigger. Do not invent claims or publish anything."
