# Build Roadmap

## Build Now

These directly help close or deliver the first paid sprint:

- Lead scoring workflow.
- Loom audit workflow.
- Client sprint scaffold.
- Prospect audit scaffold.
- B2B site architecture audit template.
- Buyer room template.
- Claim-proof ledger.
- Conversion optimization playbook, scorecard, and workflow.
- Sprint acceptance and delight gates.
- Retainer health score.
- Vertical audit playbooks.
- AI/search visibility prompt bank.
- Value calculator.
- Implementation handoff template.
- Client communication cadence.
- Command center and metrics dashboard.
- Internal owner dashboard with next actions, pending actions, bottleneck, retention risk, and 11/10 blockers.
- Retention dashboard and automatic weekly/monthly client checkup prep.
- Client-facing proof dashboard for shipped work, learnings, next action, approved proof, and missing proof warnings.
- Month-end renewal review that blocks renewal or upsell asks until value evidence is clean.
- Proof and learning library.
- Prospecting query bank and first-50 template.
- Warm-network scripts.
- Batch prospect import.
- Recording sharpness briefs, cockpit, teleprompter, outbox, and follow-up cockpit.
- Recording quality notes that preserve the leak, impact, fix, and ask into every send package.
- Sender-aware channel guidance and dirty-sender email blocking in send packages, recording, outbox, follow-up, and batch-sent flows.
- Revenue page conversion audit skill.
- Marketing-agent workbench for daily research, content, competitor monitoring, lead research, briefings, and paid ads ops.
- Market parity readiness gate for honest 11/10/comparable/better-than-market claims.
- 11/10 proof run that converts parity blockers into exact proof-capture actions.
- Reply prep, call-booked prep, sales-call prep, and post-call close package.
- Client delivery cockpit.
- Weekly Growth Desk workflow.
- Full-Stack Growth Desk workflow and channel readiness scorecard for SEO, paid ads, email/SMS, content, social, reputation, analytics, CRO, creative, and automation expansion.
- Full-stack service map generator for keeping pricing/channel scope visible and current.
- Simple repo check that required workflows exist.

## Build After First Paid Sprint

Only build these after real delivery exposes the repeated pain:

- Client intake form.
- Prospect tracker spreadsheet or CRM, only if folder state becomes hard to manage.
- Public before/after case study, only after approved proof exists.
- Deeper weekly report automation with analytics ingestion.
- Email templates for follow-up and referrals.

## Do Not Build Yet

- Complex agent orchestration.
- Paid ads for TinyStudio.
- Public marketing site with many pages.
- Automated publishing into client systems.
- Hiring workflow.

## First Software Worth Building

The first useful software is a folder-based operating cockpit plus proof-aware dashboards.

It should:

- create the client folder
- copy the client brain template
- create the intake file
- create the sprint plan
- remind us which approvals are missing
- show the current delivery board
- show the client-facing proof dashboard
- show the guarded month-end renewal review
- show the internal action list and retention checkups
- collect proof and learning back into the operating system

## Decision Rule

If a build does not help close, deliver, measure, or retain the first client, defer it.
