Order

  1. Connect an outbound sending provider (Cloudflare Email Routing forwards inbound mail only and cannot send).
  2. Add the sender postal address in agency-config.json (business address, PO box, or private mailbox).
  3. Enable DKIM in the outbound provider and copy the selector.
  4. Add the DKIM TXT record in Cloudflare DNS at resend._domainkey.tinystudio.io.
  5. Save the selector as dkimSelector.
  6. Run npm run send:setup.
