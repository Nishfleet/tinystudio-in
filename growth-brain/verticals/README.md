# Vertical Playbooks

Use these to make Loom audits faster and more specific.

## Default Order

Start with B2B/local-service verticals where one lead can be worth enough to justify the sprint:

1. Managed IT and cybersecurity/compliance.
2. Accounting, bookkeeping, and tax advisory.
3. Dental, med spa, and specialist clinics.
4. High-value home services.

## How To Use

1. Pick one vertical for the day.
2. Read the playbook.
3. Build a 20-prospect list.
4. Score the top 10.
5. Record Looms only for 8+ scores.

## Rule

Do not mix verticals all day. One vertical per day makes pattern recognition faster.
