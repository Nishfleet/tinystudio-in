# Revenue Page Conversion Audit

Use this skill when a page, form, ad, or email needs to become more likely to create qualified action.

## Source Of Truth

Read these repo files first:

- `growth-brain/quality/conversion-optimization-playbook.md`
- `growth-brain/quality/conversion-optimization-scorecard.md`
- `growth-brain/quality/search-trust-layer.md`
- `growth-brain/workflows/conversion-audit-workflow.md`

## Inputs

- Page URL or draft
- Page type
- Traffic source
- Target buyer
- Offer
- Current proof
- Analytics or visible page evidence
- Competitor/reference notes if available

## Method

1. Score the first five critical checks before writing copy.
2. Score the rest of the page only after the critical checks are understood.
3. Rank the top 5 failures by likely buyer impact.
4. Give one exact fix per failure.
5. Rewrite only the sections needed to fix the faults.
6. Run the direct-response copy sequence.
7. Run the So-What chain.
8. Pick one positioning angle.
9. Add the search trust layer only after the conversion fix is clear.
10. Add the distribution or follow-up path.
11. Mark approval-needed claims.

## Output

Return:

- Critical check table
- Top 5 failures
- Exact fixes
- Copy rewrite
- Angle decision
- Search trust layer
- Measurement plan
- Claims needing approval

## Guardrails

- Do not invent proof, customer quotes, statistics, discounts, deadlines, policies, guarantees, or results.
- Do not copy competitor language or creator screenshots verbatim.
- Do not present internal heuristics as public proof.
- If sender setup is dirty, do not recommend cold email as the first channel.
- Do not recommend buying backlinks, link schemes, fake citations, fake reviews, spam directory blasts, doorway pages, or ranking guarantees.
